# Elis ve Lila Ders APK
Aynı haftalık program; Elis ve Lila için ayrı tamamlanma takibi. Ders saatleri, türleri ve alarmlar düzenlenebilir.
GitHub Actions > Elis Lila Ders APK > Run workflow ile APK oluşturulur. Başarılı çalışmanın Artifacts bölümünden indirilir.
Android 12+ için exact alarm iznini, Android 13+ için bildirim iznini verin. Piyano dersi saati başlangıçta örnektir.
Not: Bu ilk sürüm gerçek cihazda henüz doğrulanmamıştır.
